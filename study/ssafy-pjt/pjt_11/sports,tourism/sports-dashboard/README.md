# 데이터 시각화 프로젝트

## 프로젝트 개요
Vue.js 3 기반의 스포츠 및 여행/관광 데이터 시각화 대시보드입니다.
Chart.js와 ECharts를 활용하여 다양한 데이터를 시각적으로 표현합니다.

---

## 스포츠 데이터 시각화 (F301~F306)

### 사용 데이터
- 파일명: `sports.jsonl`
- 주요 컬럼: `sport_type`, `date`, `attendance`, `viewership_rating_percent`

### 구현 차트 목록
| 요구사항 | 차트 유형 | 설명 |
|---|---|---|
| F301 | 막대 차트 | 종목별 경기 수 비교 |
| F302 | 이중 막대 차트 | 종목별 평균 관중 수 / 시청률 비교 |
| F303 | 라인 차트 | 월별 경기 수 추이 |
| F304 | 산점도 | 관중 수 vs 시청률 상관관계 |
| F305 | 대시보드 | 4개 차트 통합 화면 |
| F306 | 날짜 필터 | 연월 범위 선택 필터링 |

## 자유 데이터 시각화 (F307~F312)

### 1. 데이터 선택 이유 (F307)
- 파일명: `travel_tourism.jsonl`
- 선택 이유: 여행지별 비용, 방문자 수, 만족도 등 다양한 수치 지표가
  포함되어 있어 비교, 분포, 상관관계 등 다양한 시각화가 가능하기 때문에 선택했습니다.
- 시각화 주제: **"어떤 여행지가 가성비와 만족도가 높은가?"**

### 2. 데이터 구조 분석
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| destination | String | 여행지 이름 |
| country | String | 국가 |
| type | String | 여행 유형 (휴양, 관광 등) |
| average_cost_krw | Number | 평균 비용 (원) |
| number_of_visitors | Number | 연간 방문자 수 |
| satisfaction_rating | Number | 만족도 (5점 만점) |
| peak_season | String | 성수기 |

### 3. 시각화 설계 의도 및 데이터 가공 방식 (F310)

#### 📊 여행지별 평균 비용 · 만족도 비교 (F308)
- **설계 의도**: 비용과 만족도를 동시에 비교하여 가성비 좋은 여행지를
  한눈에 파악할 수 있도록 가로 막대 차트를 선택했습니다.
- **데이터 가공**: 이중 Y축을 사용해 단위가 다른 두 지표(원, 점수)를
  하나의 차트에 표현했습니다.
- **인사이트**: 비용이 높다고 해서 반드시 만족도가 높지 않으며,
  동남아 여행지의 경우 저비용 고만족 패턴이 나타납니다.

#### 🌸 성수기별 여행지 분포 (F309)
- **설계 의도**: 어느 계절에 여행 수요가 집중되는지 파악하기 위해
  도넛 차트를 선택했습니다.
- **데이터 가공**: `peak_season` 컬럼이 "봄, 가을"처럼 복수값을 가질 수 있어
  `,`로 분리 후 각각 집계했습니다.
- **인사이트**: 봄과 가을에 성수기가 집중되며, 겨울 성수기 여행지는
  주로 따뜻한 기후의 휴양지임을 확인할 수 있습니다.

#### 🫧 비용 vs 만족도 버블 차트 (F308+F312)
- **설계 의도**: 비용, 만족도, 방문자 수 세 가지 지표를 동시에 표현하기 위해
  버블 차트를 선택했습니다. 버블 크기로 방문자 수를 표현했습니다.
- **데이터 가공**: 방문자 수의 범위가 너무 커서 `Math.sqrt()`로
  스케일을 조정해 버블 크기를 시각적으로 균형있게 표현했습니다.
- **인사이트**: 방문자가 많은 여행지가 반드시 만족도가 높지는 않으며,
  틈새 여행지 중 높은 만족도를 보이는 곳이 존재합니다.

### 4. 인터랙티브 기능 (F312)
- 여행 타입 필터 (휴양, 관광, 역사 등)
- 성수기 필터 (봄, 여름, 가을, 겨울)
- 필터 변경 시 모든 차트와 요약 카드가 동시에 실시간 갱신
