# 📋 투자자 정보 및 포트폴리오 관리 시스템 구현 리포트

## 1. 프로젝트 개요
본 프로젝트는 투자자의 개인 신상 정보와 금융 포트폴리오 성향을 관리하는 대시보드 시스템 구축을 목표로 합니다. **현대적인 Bento Grid 레이아웃**과 **반응형 웹 디자인**을 적용하여 사용자 경험(UX)을 극대화하였으며, HTML과 CSS를 페이지별로 분리하여 산출물 규격을 준수했습니다.



---

## 2. 단계별 구현 과정 및 학습 내용

### ✅ [F-301] 프로필 및 투자 성향 파트
- **학습 내용**: `Grid` 시스템을 활용하여 프로필 이미지와 투자 스타일 섹션을 효율적으로 배치했습니다. 프로필 이미지는 요구사항에 따라 타원/원형 형태와 입체적인 그림자(`shadow-2xl`) 속성을 반드시 포함하도록 설계했습니다.
- **기능**: 투자 스타일은 단일 선택이 가능하도록 구현했으며, 관심 종목 및 상품 선호도는 중복 선택(`checkbox`)이 가능하도록 UI를 구성했습니다.

### ✅ [F-302] 기본 회원 정보 출력
- **학습 내용**: 폼(Form) 요소의 다양한 `type` 속성을 실무에 적용했습니다. 나이와 자산 필드는 `number` 타입을 지정하여 숫자 이외의 입력을 제한했습니다.
- **제약 조건**: 회원 번호와 ID 필드에는 `readonly` 속성을 부여하고, 잠금(`lock`) 아이콘을 배치하여 수정 불가능한 데이터임을 시각적으로 강조했습니다.

### ✅ [F-303] 네비게이션 바 (Navigation Bar)
- **학습 내용**: `sticky-top` 설정을 통해 스크롤 시에도 메뉴가 상단에 고정되도록 구현했습니다. `profile.html`과 `portfolio.html` 사이를 유연하게 이동할 수 있도록 링크를 구성했습니다.

### ✅ [F-304] 포트폴리오 정보 관리
- **학습 내용**: 저축 성향(짠테크형, 중립형, 플렉스형)을 카드형 선택 UI로 구현했습니다. 클릭 시 테두리 색상과 체크 아이콘이 즉시 변경되도록 JavaScript DOM 제어 로직을 적용했습니다.
- **기능**: 포트폴리오 페이지에서도 본인의 회원 번호와 ID를 상단에 노출하여 사용자 식별이 가능하도록 했습니다.

### ✅ [F-305] 반응형 디자인 최적화
- **학습 내용**: **Media Query**를 사용하여 768px 미만(모바일 환경)에서 레이아웃이 최적화되도록 구성했습니다.
- **결과**: 화면이 좁아지면 가로로 배치되었던 투자 성향 파트가 자기소개 섹션 하단으로 자연스럽게 정렬됩니다.

## 3. 어려웠던 부분 및 해결 방법

1. **JavaScript 상태 동기화**: 
   - **문제**: 포트폴리오 탭에서 카드를 클릭할 때 이전 선택 상태가 초기화되지 않는 버그가 있었습니다.
   - **해결**: `forEach`문을 사용하여 클릭 시 모든 카드의 활성화 클래스를 먼저 제거한 뒤, 선택된 요소에만 클래스를 추가하는 로직으로 수정하여 해결했습니다.

2. **아이콘 라이브러리 연동**:
   - **문제**: JS로 아이콘의 `data-lucide` 속성을 변경해도 화면에 즉시 반영되지 않았습니다.
   - **해결**: 속성 변경 직후 `lucide.createIcons()`를 재호출하여 아이콘 라이브러리가 화면을 갱신하도록 처리했습니다.

## 4. 새로 배운 것들 및 느낀 점

- **UX 디테일의 차이**: 단순한 입력창보다 포커스 시의 컬러 변화나 부드러운 전환 효과(`transition`)가 사용자에게 주는 신뢰감이 훨씬 크다는 점을 배웠습니다.
- **파일 구조화의 중요성**: HTML과 CSS를 독립적으로 분리하면서 코드의 가독성이 좋아지고, 특정 페이지의 스타일만 수정할 때 다른 페이지에 영향을 주지 않아 유지보수가 매우 편리해짐을 느꼈습니다.
- **반응형 웹의 핵심**: 단순히 크기를 줄이는 것이 아니라, 정보의 우선순위에 따라 레이아웃의 순서를 재배치하는 기획적 고민이 중요하다는 것을 깨달았습니다.
