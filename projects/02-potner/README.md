# Potner — 반려식물 AIoT 로봇

> Pot + Partner. 스스로 판단하고 움직이며 사용자와 교감하는 반려식물 로봇
> SSAFY 15기 공통 프로젝트 · E104 팀

- **저장소**: [gbw11/Potner](https://github.com/gbw11/Potner) (팀 GitLab의 파트별 브랜치를 모은 스냅샷)
- **담당**: `raspberry/` 장치 스테이션 **전담** (커밋 55개, 사실상 전량) + `robot/` LLM·음성 대화 서브시스템 (커밋 31개, 기여도 2위)

## 개요

판단은 서버, 이동은 로봇, 센서 수집과 급수·송풍·촬영은 집안 거치대(장치 스테이션)가 맡습니다.

| 파트 | 스택 | 역할 |
|---|---|---|
| `app/` | Flutter | 식물 상태 확인, 원격 급수/송풍, 귀가 알림 |
| `server/` | Spring Boot, MQTT, YOLO | 판단·조율 서버 |
| `robot/` | ROS2 (Jetson Orin Nano) | SLAM 자율주행·도킹, 음성 대화, LLM 브리지 |
| `raspberry/` | Python (Raspberry Pi) | 센서 수집, 급수·송풍, 카메라 촬영 |

## 담당 역할

### 장치 스테이션 (`raspberry/`) — 전담
- **센서 통합**: 조도(BH1750), 온습도(DHT22/AHT20), 토양수분(ADS1115), 수위 플로트 스위치
- **수위 감지 채터링 해결**: 유지시간 필터 → 접촉 인정 기준을 명시화하며 반복 개선
- **급수 펌프 안전 게이트**: MQTT 원격 제어 + 과급수 방지(1회 상한 · 최소 간격 · 24시간 누적 상한)
- **카메라 파이프라인**: 원격 촬영 명령 → 밝기 검사 → 실패 시 재시도 → 서버 업로드, 녹색빛 화이트밸런스 핫픽스
- **MQTT**: 하트비트 발행, device ID 정합성, 명령/결과 토픽을 서버 규약에 맞춰 정렬

### LLM · 음성 대화 (`robot/`) — 설계·구현
핵심 원칙: **판정은 항상 코드가 하고, LLM은 그 위에서 말만 한다.**

- **사실성 검증(factcheck) 파이프라인**: LLM 답변을 실제 센서값과 대조해 어긋나면 재생성, 그래도 틀리면 정해진 문구로 폴백 → 센서값을 지어내는 환각을 구조적으로 차단
- **E2E 증명**: 파일 폴백에 트랩값(99.9°C)을 심어 두고 답변에 등장하지 않는 것으로 "서버 실측 → 툴 → factcheck → 답변" 경로를 검증
- **센서 데이터 소스 추상화**: 파일/HTTP/콜백 3종, NO_DATA(값 제외)와 STALE(값은 쓰되 재판정)의 의미 구분
- **Tool use**: 날씨 · 식물 지식 · 뉴스 · 위키백과 검색 툴 연결, Claude 모델로 전환
- **식물 시점 일기 생성**: 페르소나·형식·사실성 제약 + 실패 시 템플릿 폴백
- **음성 파이프라인**: 휴대폰 음성 → STT → LLM → TTS → 로봇 스피커
- 장치 스테이션용 대화 모듈을 의존성 없이 `potner_llm` 패키지로 재설계해 Jetson ROS2에서 재사용
